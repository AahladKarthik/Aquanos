# Aquanos
Smart fish catching companion
- Developed a machine learning system using scikit-learn to predict fish school locations with 80%
accuracy, leveraging environmental and geospatial datasets.
- Engineered data pipelines with pandas for efficient parsing, preprocessing, and integration of
user-contributed fish data to continuously improve model accuracy.
- Applied geopy for distance calculations to enhance location-based predictions and optimize results for
real-world use by fishermen.
